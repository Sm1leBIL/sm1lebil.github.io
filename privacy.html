Privacy Policy

Scope

This policy describes the personal Framebeats Local Studio workflow operated by the FrameBeats channel owner (GitHub: Sm1leBIL). Access is intended for the owner, not a public sign-up service.

Google information accessed

With the owner’s authorization, the tool reads the selected channel identity, video metadata, and aggregate YouTube Analytics reports. It also requests public video metadata for topic and competitor research. It uploads original video files with titles, descriptions, audience settings and publication times.

How the information is used

Google API information is used to operate the owner-authorized music content workflow, confirm the destination channel, prevent duplicate uploads, select topics, and evaluate performance. The application has no model-training feature and does not sell Google API data or use it for advertising profiles.

AI and speech services

Codex performs research and editorial analysis through the operator’s account, which may process selected workflow information using OpenAI services. The operator must configure provider data controls consistently with Google’s Limited Use requirements. ElevenLabs receives the narration text, speech settings and its own authentication key for speech requests; Google OAuth credentials are not included in those requests.

Local storage and retention

OAuth credentials are stored locally in owner-only files. Original scripts, audio, animations, video exports and publication receipts remain on the operator’s Mac. Current API research and analytics snapshots are refreshed during operation; operational checks remove stale snapshots older than 29 days. The application must be operated and maintained so applicable API retention limits are met.

Revoking access and deletion

The operator can revoke Framebeats Local Studio in Google Account Connections and use the local revocation function to remove its token and API caches. Original creative files and publication records can be deleted by the operator. Removing local access does not delete or unschedule videos already stored on YouTube.

Hosting and service providers

These information pages are hosted by GitHub Pages, which may process web access information under the GitHub Privacy Statement. These pages do not request Google sign-in, accept credentials or embed analytics scripts. Google, OpenAI and ElevenLabs process their respective requests under the agreements and controls applicable to the operator’s accounts.

Limited Use

Use and transfer of information received from Google APIs must comply with the Google API Services User Data Policy, including its Limited Use requirements. The operator is responsible for keeping this statement and the actual workflow aligned.

Contact

Contact the operator through the public information repository. Do not post credentials or private data. The Google consent screen also provides a support contact.
